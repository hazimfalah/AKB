# Materi Diskusi — AKB

Folder ini disiapkan untuk menyimpan rangkuman diskusi, keputusan, dan rencana tindak lanjut terkait pengembangan CV. Aneka Konveksi Bandung (AKB).

## Topik diskusi yang akan didokumentasikan

| Topik | Cakupan |
| --- | --- |
| Profil & strategi bisnis | Posisi AKB sebagai penyedia seragam, kerja sama B2B, dan pengembangan usaha |
| Marketing & kunjungan sekolah | Pendekatan sekolah baru, materi presentasi, katalog, sampel, dan tindak lanjut |
| Penawaran & komunikasi klien | Alur permintaan harga, proposal, tender, serta komunikasi profesional |
| Produksi & persediaan | Perencanaan kebutuhan kain, stok per jenis/warna, dan pelacakan proyek |
| Katalog & identitas visual | Penyusunan katalog produk, foto seragam, dan materi promosi |
| Sistem digital | Website, portal pemesanan, dan pencatatan operasional |
| Administrasi & legalitas | Struktur usaha, perizinan, dan dokumentasi kerja sama |

## Format catatan berikutnya

Setiap pembahasan dapat dibuat sebagai file Markdown terpisah di folder ini, dengan susunan:

1. **Tanggal dan judul diskusi**
2. **Latar belakang / permasalahan**
3. **Alternatif yang dibahas**
4. **Keputusan yang disepakati** (jika ada)
5. **Tindak lanjut, penanggung jawab, dan tenggat** (jika ada)

> **Perhatian:** Repository `hazimfalah/AKB` saat folder ini dibuat berstatus **public**. Jangan mengunggah data pribadi, kontrak, rincian harga khusus pelanggan, atau informasi bisnis rahasia tanpa mengubah pengaturan akses dan mengecek isinya terlebih dahulu.
